# shreya.exe

*intended digital footprint ig*

A personal corner of the internet. Built with React, Vite, Three.js and React Three Fiber.

## Run locally

\`\`\`bash
npm install
npm run dev
\`\`\`

## Build

\`\`\`bash
npm run build
\`\`\`

## Deploy

Push to \`main\`. GitHub Actions builds the site and deploys it to GitHub Pages.

Before publishing, replace the clearly marked sample content and social links in \`src/App.jsx\`.
